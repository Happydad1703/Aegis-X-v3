# 외부기관 목록 및 통신점검 (Aegis-X v3)

**목적**: FRED·ECOS·DART·KIS·뉴스·LLM 등 시스템이 연동하는 **모든 외부기관**을 목록화하고, 통신점검(check_comm) 항목 및 저장소(DB)와 연결한다.

**원칙**: 모든 API Key는 **Windows 11 환경변수**에만 설정. `backend/app/core/env_keys.py`에서만 조회. (SE-17, 16_Config)

## 2. 통신점검 실행 (v3)

**실행**: `python scripts/check_comm.py`

**현재 점검 순서**: FRED → OpenAI → Gemini → KIS

**점검 내용**  
- **FRED**: FRED_API_KEY로 시리즈(GDP) 1건 요청. 200이면 OK.  
- **OpenAI**: OPENAI_API_KEY로 /v1/models 조회. 200이면 OK.  
- **Gemini**: GEMINI_API_KEY로 generateContent 최소 요청. 200/201 또는 429(rate limited)면 OK.  
- **KIS**: KIS_APP_KEY, KIS_APP_SECRET으로 모의투자 토큰 발급. 200 + access_token 있으면 OK.

**결과 해석**  
- **OK**: 해당 기관과 통신 성공.  
- **SKIP (xxx not set)**: 환경변수 미설정. 선택 항목이면 무시 가능.  
- **FAIL**: 키 오류 또는 네트워크/API 오류 → 변수값·네트워크 확인.

**확장**  
- ECOS, DART, Anthropic, DeepSeek 점검을 넣으려면 `scripts/check_comm.py`에 함수 추가 후 `main()`의 results에 append.  
- env_keys에는 이미 ECOS_API_KEY, DART_API_KEY, ANTHROPIC_API_KEY, DEEPSEEK_API_KEY 조회 함수 존재.

## 3. 저장소(DB) 연결 요약 (v3)

| 외부기관 | 기록 대상 (v3) |
|----------|----------------|
| FRED, ECOS, DART | macro_context (마이그레이션 확장 시), 또는 ext_event_raw (event_type·source_name 구분) |
| 뉴스 6종 | ext_event_raw (event_type=NEWS_EVENT, source_name=Naver/Finnhub/AlphaVantage/Yonhap/Edaily 등) |
| KIS | order_log (주문·체결), engine_snapshot (portfolio_state 등 스냅샷) |
| LLM | engine_snapshot (regime_current, llm_status 등) |
| 인프라 | PostgreSQL (ext_event_raw, engine_snapshot, order_log, incident_log, command_log, system_mode, system_config) |

v3는 **DB-First**: 모든 수집·산출은 DB에 기록 후, UI/API는 engine_snapshot 등 **DB만 조회**. (state_ledger.json 등 파일 Ledger는 ICD 확장 시 정의)

## 4. 수집 모듈·저장 DB·리프레시 (v3 설계)

| 자료원 | 수집 모듈 (v3) | 저장 DB(테이블) | 리프레시(ICD) |
|--------|----------------|-----------------|---------------|
| **FRED** | workers/ingest_worker 또는 collectors (확장 시) | ext_event_raw / macro_context | 1시간 |
| **ECOS** | 동일 | ext_event_raw / macro_context | 1시간 |
| **DART** | 동일 | ext_event_raw (DART_EVENT), macro_context | 1시간 |
| **네이버 뉴스** | ingest_worker 연동 시 | ext_event_raw (NEWS_EVENT) | 3분 |
| **다음/Kakao** | 동일 | ext_event_raw (NEWS_EVENT) | 5분 |
| **연합인포맥스 RSS** | 동일 | ext_event_raw (NEWS_EVENT) | 5분 |
| **이데일리 RSS** | 동일 | ext_event_raw (NEWS_EVENT) | 5분 |
| **Finnhub / Alpha Vantage** | 동일 | ext_event_raw (NEWS_EVENT) | 5분 / 12분 |
| **KIS** | execution/kis_executor, 주문·잔고 동기화 | order_log, engine_snapshot | 60~300초 |

**v3 경로**  
- 키 조회: `backend/app/core/env_keys.py`  
- 통신 점검: `scripts/check_comm.py`  
- 수집: `workers/ingest_worker.py` (연동 시), Single Write Path 준수 (repo/core 경유)
