# 한국 뉴스·기업정보 소스 정리 (Aegis-X v3)

v3에서 **한국 뉴스·기업정보** 소스와 **API Key 환경변수**를 정리합니다.  
모든 API Key는 **Windows 11 환경변수**에만 설정하며, `backend/app/core/env_keys.py`에서만 조회합니다. (SE-17, 16_Config)

---

## 1. 현재 v3에서 사용·지원하는 소스

### 1.1 한국 뉴스

| 소스 | 용도 | 환경 변수 (API Key) | 비고 |
|------|------|---------------------|------|
| **네이버 검색(뉴스)** | 키워드별 뉴스 검색 | `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET` | [네이버 개발자센터](https://developers.naver.com/) → 애플리케이션 등록 → 뉴스 검색 API. |
| **다음(Daum) / Kakao 검색** | 웹문서 검색(뉴스·시장 심리 보조) | (v3 슬롯 없음 → 추가 시 `KAKAO_REST_API_KEY`) | [Kakao 개발자](https://developers.kakao.com/) REST API 키. v2 참고. |
| **연합인포맥스 RSS** | 전문통신 속보 (증권/IB/정책·금융) | **없음** | 공개 RSS. ICD 03: Yonhap RSS, Ledger 저장. |
| **이데일리 RSS** | 전문통신 속보 (증권·특징주·M&A) | **없음** (선택: `EDAILY_RSS_URL`) | ICD 03: Edaily RSS. 기본 URL 사용 가능. |

### 1.2 기업정보·공시

| 소스 | 용도 | 환경 변수 (API Key) | 비고 |
|------|------|---------------------|------|
| **DART (전자공시)** | 공시 목록·보고서 검색 | `DART_API_KEY` | [DART Open API](https://opendart.fss.or.kr/) 무료 인증키. env_keys: `ENV_DART_API_KEY`. |

### 1.3 매크로·증권·브로커

| 소스 | 용도 | 환경 변수 | 비고 |
|------|------|-----------|------|
| **FRED** | 미국 매크로 | `FRED_API_KEY` | check_comm.py 통신 점검 대상. |
| **ECOS** | 한국 선행지표 등 | `ECOS_API_KEY` | env_keys에 슬롯 있음. |
| **KIS (한국투자증권)** | 잔고·주문·포지션 | `KIS_APP_KEY`, `KIS_APP_SECRET` | check_comm.py 통신 점검 대상. |

### 1.4 뉴스원별 전략적 포지션 (Macro vs Micro)

| 뉴스원 | 담당 분야 | Aegis-X 내부 역할 |
|--------|-----------|--------------------|
| **연합인포맥스** | 금리, 환율, 국채, 매크로 | 시장 전체의 '날씨' 판단 (방패) |
| **이데일리** | 특징주, M&A, 증권가 속보 | 개별 타겟의 '급소' 포착 (창). 인포맥스와 교차 검증. |
| **네이버/다음** | 대중 심리, 검색량 | 작전의 '과열' 상태 감지 |

- **인포맥스**: 거시/기관 톤. 한은, 기재부, 채권·금리·환율에 강함.
- **이데일리**: 리서치·개별 종목 속보, 테마주, 공시 해석, IB/M&A 소식에 강함.
- 두 소스 동시 수집 시 JCS/LLM 교차 검증으로 "실질 호재" 판단 정확도 향상.

## 3. 추가 시 API Key가 필요한 기관

| 기관 | 용도 | 예상 환경 변수 | 비고 |
|------|------|----------------|------|
| **한국거래소(KRX) 데이터** | 시세·거래대금·지수 | `KRX_API_KEY` | 데이터몰 등 유료 서비스 이용 시. env_keys에 추가 필요. |
| **Kakao 검색** | 웹/뉴스 검색 | `KAKAO_REST_API_KEY` | env_keys에 상수·getter 추가 후 ingest 연동. |

## 4. API Key 발급 요약 (한국 소스)

1. **네이버** — `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`  
   발급: [developers.naver.com](https://developers.naver.com/) → 애플리케이션 등록 → 뉴스 검색 API.

2. **DART** — `DART_API_KEY`  
   발급: [opendart.fss.or.kr](https://opendart.fss.or.kr/) → 인증키 신청(무료).

3. **Kakao** (선택) — `KAKAO_REST_API_KEY`  
   발급: [developers.kakao.com](https://developers.kakao.com/) → 앱 생성 → REST API 키.  
   v3에 슬롯 추가 후 사용.

4. **연합인포맥스 / 이데일리 RSS** — API Key 없음. 공개 RSS URL 사용.
